# Huffman Archiver

Учебный архиватор, написанный на C.

Программа позволяет объединять несколько файлов в один архив и сжимает каждый файл с помощью алгоритма Хаффмана. Для архива используется собственный простой бинарный формат.

## Возможности

* создание архива из нескольких файлов;
* сжатие данных алгоритмом Хаффмана;
* извлечение отдельных файлов из архива;
* удаление файлов из существующего архива;
* просмотр содержимого архива;
* проверка архивных данных;
* собственный бинарный формат `.harc`.

## Использование

### Добавить файлы в архив

```bash
./archive -a archive.harc file1.txt file2.txt
```

### Посмотреть содержимое

```bash
./archive -l archive.harc
```

### Извлечь файлы

```bash
./archive -x archive.harc file1.txt file2.txt -o output1.txt output2.txt
```

### Удалить файлы

```bash
./archive -d archive.harc file1.txt
```

### Проверить архив

```bash
./archive -t archive.harc
```

### Справка

```bash
./archive -h
```

## Как устроено сжатие

Для каждого файла программа:

1. подсчитывает частоту появления каждого байта;
2. строит дерево Хаффмана;
3. получает двоичный код для каждого символа;
4. сохраняет дерево и закодированные данные в архив;
5. при распаковке восстанавливает дерево и исходный файл.

Для записи кодов переменной длины реализована отдельная работа с отдельными битами внутри байтов.

## Формат архива

Архив начинается с заголовка `HARC` и содержит таблицу файлов.

Для каждого файла хранятся:

* имя;
* исходный размер;
* размер сжатых данных;
* смещение данных внутри архива.

После таблицы последовательно располагаются сжатые данные файлов.

## Структура проекта

```text
.
├── main.c
├── archive.c
├── archive.h
├── huffman.c
├── huffman.h
├── bit_work.c
└── bit_work.h
```

* `main.c` — обработка аргументов командной строки;
* `archive.c` — работа с архивом и его форматом;
* `huffman.c` — сжатие и распаковка алгоритмом Хаффмана;
* `bit_work.c` — чтение и запись отдельных битов.

## Сборка

Например, с помощью GCC:

```bash
gcc main.c archive.c huffman.c bit_work.c -o archive
```
